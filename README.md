# Full-Stack Social Media Application

A full-stack social media web application built with React, Node.js, Express, and MariaDB. The project includes user accounts, profiles, posts, friendships, likes, comments, and reposts.

## Features

- User registration and sign-in
- User profiles
- Create and view posts
- Profile and header image uploads
- Friend requests and friendship management
- Like and comment functionality
- Repost functionality
- Protected routes for authenticated users
- Relational database integration

## Technologies Used

**Frontend**
- React
- Vite
- React Router
- CSS Modules

**Backend**
- Node.js
- Express.js
- REST API

**Database**
- MariaDB
- SQL

## Getting Started

### Prerequisites

- Node.js and npm
- MariaDB
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Valasc0/social-media-app-full-stack-.git
cd social-media-app-full-stack-
```

### 2. Install dependencies

```bash
cd backend
npm install
```

Then install the frontend dependencies:

```bash
cd ../frontend
npm install
```

### 3. Configure environment variables

Create a `.env` file in the backend directory and configure your database credentials and other required environment variables.

Never upload your real credentials or secret keys to GitHub.

### 4. Set up the database

Create the MariaDB database and tables required by the application. Configure the database connection according to your backend settings.

### 5. Run the application

Start the backend and frontend in separate terminals using the scripts defined in their respective `package.json` files.
